# Lista de Tarefas com React

Projeto completo baseado na apostila `apostila-todo-react.html`.

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. No VS Code, escolha **Arquivo > Abrir Pasta** e selecione `todo-react`.
3. Abra o terminal integrado.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra o endereço exibido no terminal.

## Criar a versão de produção

```bash
npm run build
npm run preview
```
